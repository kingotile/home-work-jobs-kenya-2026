# Home Work Jobs and Tasks

Static website files for GitHub Pages.

## Publish
1. Extract this ZIP on your phone.
2. Upload the files inside it to the root of your GitHub repository. Do not upload the ZIP itself.
3. Ensure the main page is named exactly `index.html`.
4. Open repository Settings → Pages.
5. Choose Deploy from a branch, select `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to show the published address.

Safety note: This is a demo job directory. Do not enter passwords, bank details, or pay fees to unverified job listings.
